# PV-IRBench 基线结果 v0.1

发布日期：2026-11-01
评测脚本：`benchmark/eval_far.py` v0.1
复现命令：

```bash
python benchmark/eval_far.py --source own \
  --data <数据集根>/solar_panel_v3_clean --split valid \
  --weights runs/final/best.pt --conf 0.10
```

---

## 1. 评测对象

| 项 | 值 |
|---|---|
| 权重 | `runs/final/best.pt` |
| 架构 | YOLOv8s + P2 分支 |
| 类别 | ByPassed / Diode / HotSpot / StringFault（4 类） |
| 训练数据 | 多源公开数据融合，14,127 张 / 52,966 框 |
| 源图泄漏率 LSR | **0**（已通过源图级审计清零） |

## 2. 验证集

| 项 | 值 |
|---|---|
| 名称 | `solar_panel_v3_clean/valid` |
| 规模 | 503 张 |
| **负样本** | **151 张（30.0%）** |
| 正样本 | 352 张 |
| 图像尺寸 | 640×640 |

## 3. FAR–召回权衡曲线（核心结果）

| conf | FAR 假警报率 | 每千块误报框 | 图像级召回 | StringFault 召回 |
|---|---|---|---|---|
| 0.25 | 0.00% | 0.0 | 93.47% | 56.2% |
| **0.10（推荐工作点）** | **0.00%** | **0.0** | **97.44%** | **84.4%** |
| 0.05 | 0.66% | 6.6 | 97.73% | 84.4% |
| 0.01 | 2.65% | 33.1 | 98.86% | 90.6% |

**推荐工作点 conf = 0.10**：相对默认阈值，图像级召回 +3.97 个百分点，
最弱类别 StringFault 召回 **+28.2 个百分点**，而假警报率代价为零。

## 4. 逐类别结果（conf = 0.10）

| 类别 | 样本 | 命中 | 漏检 | 图像级召回 | 框级 mAP50-95 |
|---|---|---|---|---|---|
| HotSpot | 154 | 152 | 2 | 98.7% | — |
| ByPassed | 101 | 100 | 1 | 99.0% | — |
| Diode | 65 | 64 | 1 | 98.5% | 0.479 |
| StringFault | 32 | 27 | 5 | **84.4%** | **0.407** |

**关键观察**：StringFault 的框级 mAP50-95 仅 0.407（最弱），
但图像级召回可达 84.4%。说明模型"知道有问题"的能力显著强于
"精确指出问题在哪"的能力。**以 mAP 为唯一验收标准会系统性低估模型可用性。**

## 5. 跨数据集测试（负面结果，已公开）

| 数据集 | 图像尺寸 | 图像级召回 | FAR |
|---|---|---|---|
| 自有 v3_clean（同域） | 640×640 | 97.44% | 0.00% |
| InfraredSolarModules（异域） | **40×24** | **0.10%** | 0.00% |

异域召回近乎为零的原因是**尺度差异 16–26 倍**，而非模型能力问题。
该数据集本为图像级分类任务发布（MIT，Raptor Maps 2020），
不适用于框级检测评测。

**此结果作为"跨数据集指标不可比"的实证公开。**

## 6. 边界声明

- 本结果为**同域**验证集结果，**不等于真实电站表现**。
- 召回为**图像级**指标，不代表定位精度（LA 尚未实现）。
- ΔT-MAE 尚未实现（无辐射定标，不能声称℃）。
- 本结果不构成具有法律效力的检测报告。
